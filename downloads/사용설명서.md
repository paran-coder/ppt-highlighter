# PPT Highlighter v1.3.2 사용설명서
## 설치와 제거
ZIP을 풀고 PPT-Highlighter-Setup-v1.3.2.exe를 실행하여 설치합니다. 다른 PC에 설치할 때는 이 EXE 하나만 복사해 실행해도 되며, 다른 패키지 파일은 설치에 필요하지 않습니다. Windows용 데스크톱 PowerPoint가 설치되어 있어야 합니다. PowerPoint를 완전히 종료한 상태에서 설치해야 합니다. 기존 버전이 설치되어 있다면 Windows 설정의 설치된 앱에서 PPT Highlighter를 제거한 뒤 새 버전을 설치합니다. 설치 파일은 실제 탐색기에서 실행하세요.
설치 후 PowerPoint를 평소 아이콘으로 열면 하이라이트 탭이 나타납니다. 별도 프로그램을 계속 켜둘 필요가 없습니다. 제거는 Windows 설정 → 앱 → 설치된 앱 → PPT Highlighter에서 가능합니다.
## 선택 글자에 적용
1. 텍스트 상자 안에서 강조할 글자 일부를 드래그합니다.
2. 하이라이트 탭의 형광펜 색상 아이콘을 눌러 색상 칸을 선택합니다.
3. 투명도와 상하좌우 여백(pt)을 입력하고 Enter로 확정합니다.
4. 하이라이트 적용을 누릅니다. 색상 선택 자체는 문서에 적용하지 않습니다.
## 색상 메뉴
형광펜 아래 표시선은 현재 선택 색입니다. 아이콘을 누르면 20색 격자가 펼쳐집니다.
다른 색…: 기본 탭의 벌집 색상표/회색 단계에서 색을 고르거나 사용자 지정 탭에서 스펙트럼과 밝기를 조절합니다. RGB 또는 16진수 #123456으로도 직접 지정합니다. 오른쪽 새 색과 현재 색을 비교하고 확인으로 확정합니다. 취소/Esc는 기존 색을 유지합니다. 추가 창을 여는 단계와 리본의 별도 HEX 입력칸은 없습니다.
스포이드: 화면이 잠시 색상 선택 상태가 됩니다. 원하는 위치를 왼쪽 클릭하면 해당 색을 선택합니다. Esc 또는 오른쪽 클릭은 취소합니다. 선택 후 하이라이트 적용을 눌러 문서에 반영합니다.
설정은 현재 PowerPoint 실행 동안 유지되며 재실행 시 기본값으로 시작합니다.
## 자동 갱신과 호환
자동 갱신을 켜면 글자 수정·삭제에 맞추어 강조 도형을 조정합니다. 복잡한 편집으로 위치를 확정할 수 없으면 강조를 숨기며 다시 선택해 적용해야 합니다.
저장된 강조는 일반 PowerPoint 도형으로 남아 추가 기능이 없는 PC에서도 표시됩니다. 그 PC에서 글자 편집에 따라 강조를 자동 조정하는 기능은 실행되지 않습니다.
회전하지 않은 일반 텍스트 상자/텍스트 자리표시자와 투명 배경을 지원합니다. 표, SmartArt, 그룹, 회전 텍스트, 불투명 배경은 지원 범위 밖입니다.
## 기본값
노랑 #FFE865, 투명도 35%, 위/아래 1pt, 왼쪽/오른쪽 2pt. 투명도 0은 불투명, 100은 완전히 투명합니다.


## 확인된 동작과 테스트 범위
현재 PC에서 설치·리본 자동 로딩·정상 재실행을 확인했습니다. 색상 창은 PowerPoint 중앙 위에 표시되며, RGB·HEX 입력 중 글자 간격 문제를 수정하고 사용자 확인을 받았습니다. 다른 PC와 Office 버전 조합에서의 설치·편집·저장·제거는 추가 시험 대상입니다.


## v1.3.2 색상 창 수정
기본 팔레트는 제공된 PowerPoint 참조 이미지의 셀 중심 색을 기준으로 배치했습니다. 사용자 지정 스펙트럼은 HSL 방식으로 수정하고 RGB/HSL 모델을 선택할 수 있게 했습니다. PowerPoint 자체 대화상자가 아닌 자체 구현이며, Office 테마별 완전 일치는 보장하지 않습니다. 설치 교체와 실제 PowerPoint 확인은 아직 대기 중입니다.
