선택은 글자 안에서

02

설정 변경 후 적용

색상·투명도·여백 변경은 현재 설정을 바꿉니다. 문서에 반영하려면 해당 글자를 선택하고 ‘하이라이트 적용’을 누르세요.

03

편집과 스타일은 별개

자동 갱신은 기존 강조의 위치와 범위를 편집에 맞춥니다. 새 색상을 고른다고 기존 강조의 스타일이 일괄 변경되지는 않습니다.

투명도 숫자는 무엇을 뜻하나요?

0%는 불투명한 색, 100%는 완전히 투명한 상태입니다. 기본값은 35%입니다. 값이 커질수록 강조 색이 연해집니다.

0% · 또렷하게35% · 기본값75% · 가볍게

여백은 어디를 기준으로 하나요?

선택 글자의 경계를 기준으로 네 방향을 각각 설정합니다. 양수는 강조 영역을 넓히고 음수는 줄입니다. 기본값은 위·아래 1pt, 왼쪽·오른쪽 2pt입니다.

단위 · pt범위 · −72~144네 방향 독립 설정

원래 글자는 그대로 편집하고, 강조는 뒤쪽의 일반 도형으로 남깁니다. 별도 이미지로 글자를 바꾸는 방식이 아닙니다.

설치 전 참고해주세요.

검증한 환경

Windows용 Microsoft 365 데스크톱 PowerPoint에서 개발·검증했습니다. 현재 PC에서 설치, 리본 자동 로딩과 정상 재실행을 확인했습니다.

다른 Office 버전

Microsoft 365 전용으로 제한한 것은 아니지만 Office 2019·2021·2024 등 다른 PC와 버전 조합은 실제 검증하지 않았습니다. 설치 전 해당 환경에서 테스트해주세요.

지원하지 않는 설치 환경

Mac용 PowerPoint와 웹 PowerPoint에는 이 Windows EXE 추가 기능을 설치할 수 없습니다.

추가 기능이 없는 PC에서 열 때

저장된 강조는 일반 도형으로 표시됩니다. 해당 PC에서 글자를 편집할 때 강조를 자동으로 조정하려면 추가 기능이 필요합니다.

지원하는 텍스트

회전하지 않은 일반 텍스트 상자·텍스트 자리표시자와 투명 배경을 지원합니다. 표·SmartArt·그룹·회전 텍스트·불투명 배경은 지원 범위 밖입니다.

복잡한 편집 이후

강조 범위를 확정할 수 없는 편집에서는 강조를 숨길 수 있습니다. 해당 글자를 다시 선택해 적용하세요.

PowerPoint 기본 텍스트 강조와 어떤 차이가 있나요?

PPT Highlighter는 선택 글자 경계에 맞춘 일반 도형을 텍스트 뒤에 생성합니다. 강조 도형의 투명도와 네 방향 여백을 독립적으로 조절하고, 추가 기능이 실행되는 동안 편집에 맞춰 조정하는 방식입니다.

색상을 고르면 바로 문서에 적용되나요?

색상 선택은 현재 설정을 바꿉니다. 원하는 글자 일부를 선택하고 ‘하이라이트 적용’을 눌러 문서에 반영하세요. 새로 고른 색과 여백이 기존 강조에 자동으로 일괄 적용되는 방식은 아닙니다.

설정은 다시 실행해도 유지되나요?

설정은 현재 PowerPoint 실행 동안 유지됩니다. 재실행하면 노랑 #FFE865, 투명도 35%, 위·아래 1pt, 왼쪽·오른쪽 2pt의 기본값으로 시작합니다. 저장된 PPT의 강조 도형은 문서에 남습니다.

수정한 글자에 강조가 잘 맞지 않으면 어떻게 하나요?

자동 갱신이 켜져 있는지 확인하고 다시 맞추기를 눌러보세요. 복잡한 편집으로 범위를 확정할 수 없어 강조가 숨겨진 경우에는 해당 글자를 다시 드래그해 적용합니다. 지원 범위 밖의 텍스트에는 적용하지 마세요.

설치할 때 다른 파일도 필요한가요?

설치 EXE 하나면 됩니다. Windows용 데스크톱 PowerPoint가 설치된 PC에서 문서를 저장하고 PowerPoint를 완전히 종료한 뒤 설치 파일을 실행하세요.

프로그램을 제거하려면 어떻게 하나요?

PowerPoint를 종료한 뒤 Windows 설정 → 앱 → 설치된 앱에서 PPT Highlighter를 제거하세요. 이미 저장한 PPT에 포함된 일반 강조 도형은 문서에 남습니다.
